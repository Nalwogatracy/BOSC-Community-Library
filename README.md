# BOSC Community Library 📚
**Empowering Uganda's Education through Open Source**

The BOSC (Bugema Open Source Computing) Community Library is a centralized, digital repository designed to provide accessible, localized educational resources for students and educators. This project serves as a model for public-sector Open Source adoption in Uganda.

---

## 🏛️ Government Strategy & Pitch
This project is designed with the **Ministry of Education and Sports (MoES)** in mind.
- **Low TCO:** Eliminates expensive proprietary licensing fees.
- **Sovereignty:** The Ministry maintains full control over the code and data.
- **Localization:** Built-in support for native languages like Luganda to bridge the digital divide.

For a detailed strategic breakdown, see [GOVERNMENT_PITCH.md](./GOVERNMENT_PITCH.md).

---

## 🚀 Features
- **Multilingual Support:** Switch between English and Luganda.
- **Categorized Resources:** Organized directories for PDFs, Videos, and Articles.
- **Open Governance:** Follows global standards for community contribution and safety.
- **Legal Compliance:** Licensed under **GNU GPL v3.0** for guaranteed transparency.
